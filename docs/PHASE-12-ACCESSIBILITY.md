# Phase 12 Accessibility Baseline

- All primary actions must expose meaningful semantic labels.
- Family graph nodes must be reachable by non-gesture navigation where the platform permits it.
- Interactive controls target at least 44x44 logical pixels.
- Text must respect system text scaling without clipping critical controls.
- Do not rely on color alone to distinguish marriage, parent-child, or selected states.
- Error states must provide readable text and an actionable retry.
- Loading states must expose progress semantics.
- Respect reduced-motion preferences for graph transitions when implemented at platform level.
- Privacy-sensitive names must not be exposed in accessibility labels when the profile is masked.
