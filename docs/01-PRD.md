# PRD — Family Network

## 1. Product vision
A lifelong family relationship network where every person can build a branch, connect overlapping identities and preserve family history across generations.

## 2. Core principles
1. Person identity is canonical and independent from account, family space and surname.
2. The underlying model is a graph; a tree is a visualization.
3. Independent relatives can join and connect existing branches.
4. No fixed generation depth.
5. Privacy is enforced before discovery/search results are exposed.
6. Uncertain identities and facts are suggested/reviewed, never silently merged.
7. Historical facts are preserved with source/evidence.

## 3. Personas
- Individual family builder
- Family contributor
- Family administrator
- Claimed person
- Genealogy/history researcher
- Platform administrator

## 4. Core jobs
- Build my family
- Find relatives
- Understand how two people are related
- Connect branches when relatives join
- Preserve memories and history
- Invite family members
- Resolve duplicate/ambiguous people safely

## 5. MVP outcomes
- User registration/login
- Create/claim person
- Add people and canonical relationships
- Basic interactive tree/network view
- Search known family
- Family spaces
- Invitations and connection requests
- Privacy controls
- Audit trail
- Admin metrics and health visibility

## 6. Growth loop
Join → build branch → invite relatives → overlapping identity detected → confirmation → branches connect → new branch expands network → more invitations.

## 7. Monetization
Free core graph and connection experience. Paid tiers monetize storage, advanced history, AI, genealogy, exports, family vault and large-family administration. Ads are kept away from sensitive/emotional surfaces and removed for paid users.

## 8. Messaging policy
Supported: email verification, password/account recovery, SMS/WhatsApp OTP, invitations, transactional notifications. Not supported by default: syncing or reading private SMS, email inboxes or WhatsApp chat histories.

## 9. Success metrics
- Activated users
- People added per activated user
- % users with 5+ relationships
- Invitation send/accept rate
- Claimed-person rate
- Confirmed cross-branch links
- 7/30/90-day retention
- Family spaces created
- Memories added
- Subscription conversion
- MRR/ARR
- Crash-free sessions
- API error rate
- Graph integrity incidents
- Duplicate/merge dispute rate

## 10. Guardrails
- Never merge on surname alone.
- Never expose private living-person information through discovery.
- Never delete relationship history without auditability.
- Never treat AI output as verified fact.
