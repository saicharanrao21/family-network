# App Flow

## Global navigation
Home | Tree | + | Search | Family

## Onboarding
Splash → Welcome → Login/Register → Verify → Create/claim self → Add immediate family → Home.

## Add person
Tap + → Choose relationship → Enter name → Optional details → Save → graph expands → invite/claim option.

## Claim person
Invitation/link → account creation/login → identity verification → claim request → existing relationships retained → privacy settings.

## Duplicate/identity match
New person → identity engine → candidate matches → context comparison → Same person / Not same / Later → merge review → canonical person + audit trail.

## Relative joins
Relative registers → creates/claims overlapping person → candidate match → confirmation → cross-family graph connection → notification → branch expansion.

## Tree
Open Tree → select focus person → choose depth/filters → progressive graph expansion → tap node → person sheet → Explore their family.

## Search
Search → Known Family / Family Spaces / Possible Connections → select person → relationship path → Explore.

## Relationship calculator
Select A and B → graph traversal → canonical relationship + exact path + confidence + alternative known paths.

## Discover
Suggested connection → why this was suggested → privacy-safe context → connect / ignore / report.

## Family space
Create/join → roles → branches → members → memories → events → documents.

## Subscription
Free usage threshold/paid feature → paywall → plan comparison → Razorpay/Stripe checkout → webhook → entitlement update → receipt/notification.

## Admin
Admin login → overview → users → family graph health → identity/merge review → subscriptions → messaging → errors → audit → feature/configuration.
